# Тестовое задание dungeon-sim
## Запуск
Клонируйте репозиторий
```
git clone https://github.com/ArpolX/dungeon-sim
```
### Локально
```
go run ./cmd
```
### Docker
```
docker build -t dungeon-sim .
docker run --rm dungeon-sim
```
## Примечания
1. Файлы `config.json` и `events.txt` лежат в директории **data**
2. Как только игрок получает итоговый статус (SUCCESS, FAIL, DISQUAL), логи о его действиях больше выводиться не будут
3. Я храню состояние локально, потому что в ТЗ не было указано иное
4. В условии есть несколько ошибок в английском, например `recieved`, я посчитал это проверкой языка и в логах исправил слова
## Где использовал LLM
Для генерации тестовых данных в больших объёмах, а также совета по разделению слоёв валидации и хендлеров
