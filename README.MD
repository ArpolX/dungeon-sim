# Тестовое задание играем в игру
## Запуск
### Локально
```
go run ./cmd
```
### Docker
```
docker build -t dungeon .
docker run dungeon
```
## На что я бы хотел обратить ваше внимание
1. Как только игрок получает итоговый статус (SUCCESS, FAIL, DISQUAL) логи о его действиях больше выводиться не будут
2. Я храню состояние локально, потому что в условии не было указано иное
